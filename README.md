# Silent Station

A clickable prototype of a participant-first recording station for Silent's hand and ultrasound data collection. Static, one page, no build: open `index.html`.

Keys: Space start and pause, Backspace redo 30 s, Esc stop and save, Enter marks a step while recording a demonstration, `d` shows the test switches.

Source of truth: `prototypes/participant-app` in the `silent-demo-p1` repository; this site is staged from it with `build-site.sh`.
